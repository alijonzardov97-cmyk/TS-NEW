# Живой тест TS (сервер дома + Tailscale + телефон)

Идём по порядку. Если шаг не прошёл, остановитесь и пришлите мне, что именно увидели
(текст ошибки, логи `docker compose logs server`, лог сборки Actions).

## 0. Подготовка (один раз)

1. Запушьте все коммиты и дождитесь зелёной сборки APK в GitHub Actions. Установите APK.
2. На ПК: установлены Docker Desktop и Tailscale, вы вошли в Tailscale. На телефоне тоже
   Tailscale (тот же аккаунт). В админке Tailscale включены MagicDNS и HTTPS-сертификаты.
3. Узнайте имя ПК в tailnet, например `mypc.tailXXXX.ts.net`.

## 1. Сервер

1. PowerShell в папке репозитория:
   `powershell -ExecutionPolicy Bypass -File scripts\local-server.ps1 -PublicUrl https://mypc.tailXXXX.ts.net -Admin alijon`
2. Затем: `tailscale serve --bg --https=443 http://127.0.0.1:8080` (никогда не `funnel`).
3. Проверка: с телефона в браузере откройте `https://mypc.tailXXXX.ts.net/api/health`. Должен
   прийти JSON со статусом. Без Tailscale на телефоне страница открываться не должна.

## 2. Подключение и вход

- [ ] Приложение просит биометрию/PIN при открытии.
- [ ] Ввод адреса сервера показывает отпечаток сертификата, подтверждаете.
- [ ] Регистрация первого аккаунта, показывается код восстановления (сохраните).
- [ ] Второй аккаунт: веб-браузер на ПК (`https://mypc.../`) или второй телефон.

## 3. Переписка

- [ ] Найти второго пользователя, начать чат, отправить сообщение в обе стороны.
- [ ] Кнопка «Код» в шапке: на обоих устройствах одинаковый номер.
- [ ] Выйти и войти заново: история на месте.

## 4. Файлы

- [ ] Отправить фото с Android: у получателя на Android отображается картинка. Проверьте,
      что в фото нет геометки (уходит перекодированным).
- [ ] Отправить документ (PDF), сохранить у получателя кнопкой «Сохранить».
- [ ] Файл больше 25 МБ: понятная ошибка.
- [ ] Из веба отправить файл на Android: должна быть надпись, что файл без шифрования и не открывается.

## 5. Звонки (нужно два устройства с Android, звонок с веба отдельно)

- [ ] Звонок Android→Android: у получателя «Входящий звонок», ответ, слышно в обе стороны.
- [ ] На обоих экранах одинаковый 20-значный код сверки.
- [ ] Микрофон/динамик/завершить работают. Свернуть приложение во время звонка: звук идёт,
      после завершения приложение просит разблокировку.
- [ ] Звонок при закрытом приложении (после настройки пуша, см. п. 6): пришло уведомление.
- [ ] Звонок Android↔веб: записать, что вышло (код сверки будет только на Android).

## 6. Уведомления (UnifiedPush)

- [ ] Установлен дистрибьютор (ntfy или другой), на главной нажать «Включить уведомления».
- [ ] Закрыть приложение, отправить сообщение с другого аккаунта: пришло уведомление, нажатие
      открывает нужный чат.

## 7. Сертификат и безопасность

- [ ] `tailscale cert` продлится сам примерно через 60-90 дней; после этого приложение
      покажет окно «сертификат изменился» с двумя отпечатками.
- [ ] После создания всех аккаунтов: в `.env` поставьте `REGISTRATION_MODE=invite_only` и
      выполните `docker compose -f docker-compose.yml -f docker-compose.tailscale.yml up -d`.
- [ ] Проверьте, что сервер не виден из локальной сети: с другого устройства в Wi-Fi
      `http://<IP ПК>:8080` не открывается.

## Что записать по ходу

Для каждого пункта, который не прошёл: что делали, что ожидали, что получили, время. Особенно
важны: ошибка сборки APK, падение приложения (сразу после запуска, при звонке или отправке
файла), отсутствие звука в звонке.
